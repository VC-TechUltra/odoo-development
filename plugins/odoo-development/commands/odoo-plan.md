Plan an Odoo implementation before coding.

**If odoo-codemode is unavailable:** Use Grep/Read and at most one versioned skill file. Proceed—do not block.

Workflow:
1. Confirm target version and edition.
2. Prefer slim local rules for stable syntax; use `codemode_search` → `codemode_execute` for schema/XML IDs/patterns.
3. Produce a phased implementation plan.

Output:
- Scope
- Confirmed facts
- Open assumptions
- Files/components affected
- Risks
- Step-by-step plan
